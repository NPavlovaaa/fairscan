# 0005. Отметка у каждого рекрутера своя

Статус: принято · 2026-10-24

## Контекст
- У стенда компании может работать несколько рекрутеров
- Двое могут поговорить с одним посетителем и решить по-разному
- Разные мнения часто обоснованы: например, на разные вакансии

## Решение
- Отметка принадлежит рекрутеру: «рекрутер → посетитель → вакансия»
- Чужие отметки видно, но изменить нельзя
- При сканировании показываем отметки коллег (если есть сеть)
- Автора отметки сервер определяет по токену, клиент его не присылает

## Последствия
+ Мнение рекрутера никогда не перезаписывается чужим
+ Нет конфликтов между рекрутерами, правила «кто главнее» не нужны
+ Компания после ярмарки видит все мнения и может заметить разногласия
- Итогового решения по кандидату в системе нет, его принимает человек
- Без сети рекрутер не узнает об отметке коллеги

## Рассмотренные варианты
1. Одна отметка компании на посетителя — затрёт другую, хотя оба мнения могут быть верными, например по разным вакансиям.
2. Разрешить править чужие отметки — рекрутер может стереть верную оценку коллеги, и никто этого не заметит.
