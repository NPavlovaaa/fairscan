# 0006. Вакансия — свободный текст

Статус: принято · 2026-10-24

## Контекст
Отметка относится к конкретной вакансии: один посетитель может подходить
на одну вакансию и не подходить на другую. Списка вакансий компании
в системе пока нет, а чтобы его завести, нужны отдельный экран
и роль администратора компании.

## Решение
Рекрутер вписывает вакансию в текстовое поле. Значение сохраняется так,
как введено. Список вакансий откладываем на вторую версию.

## Последствия
+ Не нужны экран управления вакансиями и роль администратора — MVP меньше.
+ Рекрутер не упирается в список: можно указать любую вакансию.
- Одна вакансия может быть записана по-разному («Frontend», «фронтенд»),
  поэтому пометка «мнения расходятся» может не сработать.
- Опечатка при повторном сканировании создаст вторую отметку вместо правки первой.

## Рассмотренные варианты
1. Загрузка списка из Excel — нужны разбор файла, шаблон и обработка ошибок
   формата; добавим во второй версии поверх готовой модели.
2. Список, вставленный текстом по строке — проще Excel, но всё равно нужен
   экран компании и роль администратора.
3. Подсказки из уже введённых значений — уменьшают разнобой, но без сети
   подсказки неполные; можно добавить позже, не меняя модель.
