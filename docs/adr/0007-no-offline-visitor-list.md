# 0007. Список посетителей на телефон не скачиваем

Статус: принято · 2026-10-24

## Контекст
В QR-коде посетителя только его код регистрации, без имени. Чтобы показать
имя, телефон должен найти код на сервере, а в зале ярмарки сети часто нет.

## Решение
Список посетителей заранее на телефон не скачиваем. Без сети карточка
показывает код, а имя и отметки коллег появляются после синхронизации.

## Последствия
+ На телефонах рекрутеров нет личных данных всех посетителей ярмарки.
+ Не нужна отдельная загрузка данных с сервера на телефон перед ярмаркой.
- Без сети рекрутер не может сразу сверить имя и видит в списке коды.
- Без сети рекрутер не узнает, что коллега уже отметил этого посетителя.

## Рассмотренные варианты
1. Скачивать список заранее — имя видно без сети, но на каждом телефоне
   лежат личные данные сотен людей; отложено на вторую версию.
2. Класть имя в QR — формат QR задаёт чужая система регистрации,
   а имя прочитает любой сканер.
